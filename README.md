# Omniscientrix Arcade — Omega Collection

An original collection of five browser game experiences created by **Cornelius Aurelius**.

Official creator website: https://corneliusaurelius.com/

Live arcade: https://cornelius-aurelius.github.io/Omniscientrix-Arcade-/

The arcade links to four original upgraded standalone games: Neon Block Flip OMEGA, NEON SKYRAIL, NEON ORBIT SINGULARITY and Reality Breaker. Its exclusive fifth game, **Omega Signal Memory**, is playable on the arcade itself.

## How to play Omega Signal Memory
1. Press Start Challenge.
2. Watch the glowing numbered panels.
3. Repeat the pattern by tapping, clicking or pressing keys 1–9.
4. Correct sequences advance to the next stage and earn points. A wrong guess ends the run. The best cleared stage is stored in browser localStorage.
5. Sound is optional. Replay Signal lets you review each stage once.

Games can be found with genre filters and search. No sign-in or external dependencies required. Fully static HTML/CSS/JavaScript, served through GitHub Pages.
